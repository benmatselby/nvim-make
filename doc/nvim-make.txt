1. INTRODUCTION                                       *nvim-make-introduction*

nvim-make is a Neovim plugin that lets you pick and run Make targets from a
Makefile in your project. Targets are presented in a selection menu, and the
output is displayed in a floating window.

==============================================================================
2. REQUIREMENTS                                       *nvim-make-requirements*

- Neovim >= 0.10
- plenary.nvim (https://github.com/nvim-lua/plenary.nvim)
- `make` executable in your PATH
- A `Makefile` in your project root

==============================================================================
3. INSTALLATION                                       *nvim-make-installation*

Using lazy.nvim: >lua

    {
      "benmatselby/nvim-make",
      dependencies = { "nvim-lua/plenary.nvim" },
      cmd = "NvimMake",
      opts = {},
    }
<

==============================================================================
4. USAGE                                                     *nvim-make-usage*

Run `:NvimMake` to open a picker with all available Make targets from the
nearest Makefile. Select a target to execute it. Output is shown in a floating
window that closes when you press `<Esc>` or leave the window.

==============================================================================
5. COMMANDS                                               *nvim-make-commands*

                                                                    *:NvimMake*
:NvimMake           Open the Make target picker and run the selected target.

==============================================================================
6. CONFIGURATION                                     *nvim-make-configuration*

Call the setup function to configure the plugin: >lua

    require("nvim_make").setup({})
<

Currently the setup function initialises the path to the nearest Makefile.

==============================================================================
7. HEALTH CHECK                                           *nvim-make-health*

Run `:checkhealth nvim_make` to verify that all dependencies are installed
and a Makefile is present in the project root.
